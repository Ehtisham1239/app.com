# Monthly progress upgrade — 30 October 2026

Scope: existing teacher form, admin review/edit and OQC branded certificate. The existing database workflow, rating scale, assignments, roles and publication gate remain unchanged. No new module or production student record was added.

## Changes

- Teacher form has an optional live certificate preview. Unsaved ratings/remarks update it immediately, with a Draft preview stamp and an explicit notice that parents see nothing new until admin publication. Opening or editing the preview makes no save/publish call.
- Visible saved/unsaved state. Switching student or month with unsaved work opens a Keep editing / Discard changes dialog. Browser tab exit/reload also registers a native beforeunload warning while dirty; internal CMS navigation outside those controls is not globally intercepted. The review-page link asks for a draft save before leaving with changes.
- Admin Edit uses the same accessible labelled rating controls as the teacher form, retaining the mandatory correction reason and existing history/publish logic.
- Certificate shows the student code on teacher/admin/linked-parent views and the published version only on an unstamped published certificate. OQC logo, green/gold palette and print option are retained.
