# Mobile reference, college branding and country routing

The supplied mobile reference sets the public header and hero arrangement: a white logo/menu header, mint arch portrait first, then centred Arabic text, heading and introduction. Portal remains accessible inside the mobile menu. Desktop retains its navigation and two-column hero.

The original college homepage was read on 23 October 2026. Its primary #006847, hover #004f36, emerald #10b981, mint #eefaf3/#f4fbf7 and footer #111827 match the existing tokens. Welcome, courses, benefits, onboarding, tutors, contact, feedback and articles sections follow the original white/mint grouping. Existing additional location, learning, pricing and FAQ sections remain. Unverified pupil counts, qualifications and reviews were not copied. Approved tutor/review content remains controlled by the CMS.

The floating WhatsApp action remains an accessible icon at the edge; its extra “Chat on WhatsApp” text was removed. The homepage end CTA no longer duplicates the WhatsApp action. Contact details and enquiry processing remain intact.

Mobile assets reuse the existing college photography/logo. The 160px logo is 9,302 bytes versus 28,494 bytes; the 320px hero is 15,600 bytes versus 36,548 bytes. The browser can choose the original hero for a larger/high-density display. Main heading text renders immediately, and the home contact form loads near the viewport or on request, deferring its client code from initial rendering. Homepage sharing metadata has explicit image and description fallbacks. No SEO dashboards, external IP service or new product tools were added.

Country routing reads Vercel's platform-supplied `x-vercel-ip-country` only when running on Vercel. A first homepage visit redirects temporarily (307) to one of 50 existing country routes. UK, USA and Australia map to their own pages. Unknown countries retain the general homepage. Campaign query parameters are preserved. A functional, HTTP-only preference cookie prevents repeated redirects when a visitor returns to the general homepage; `/?view=global` explicitly opens it. Direct course/blog/city/form/admin links, POSTs, prefetches and recognised search crawlers retain their original destination. Country pages and original legacy redirects remain crawlable. Only personalised redirect/preference responses are private/no-store; normal homepage HTML remains cacheable. No raw IP address is stored by this feature.

Validation includes all 50 mappings, six simulated edge countries in the local production server, manual overrides, crawler/direct-link behavior, legacy redirects, mobile/desktop layout, and a stubbed home enquiry confirmation. Simulated headers establish routing behavior, not physical tests from every country. Browser tests stub the external chat vendor. Search rankings and field Core Web Vitals are not guaranteed by these checks.
