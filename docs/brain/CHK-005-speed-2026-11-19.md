# CHK-005 Speed pass: fonts and paint

Hub: [[000-OQC-SEO-Hub]] · previous: [[CHK-004-design-2026-11-19]]

**Observed (live Lighthouse, CI run 44516872758, main 02d5ce2):** mobile home 78 (TBT 970 ms, LCP 1.3 s, CLS 0), /pricing 79, desktop 98 (CLS 0.098). Long tasks after load are GTM-W7CMZS53, GTM-52PTXDRF, GA4 destination, Ads `gtag/js?id=AW-16564445897` and Clarity. With those blocked, the local build scores 99–100 on mobile home, so first-party code is not the bottleneck.

**Bugs found and fixed (implemented, locally verified):**
1. A "≈" beside converted prices is in none of the Latin font files, yet the browser downloaded the Inter Latin and Latin-ext fallbacks (133 KB) to look for it. Added Fontsource's `unicode-range` to the three fallback faces.
2. The footer verse (20:114, on every page) used the small Arabic display subset, which lacks zay and tanween, so every page downloaded the complete 109 KB Amiri face. It now uses Amiri Quran (`.quran-text`), which the ayah band already loads. Same for the /quran-study verse.
3. The home verse shimmer animated `background-position`, which repaints every frame for ~10 s. Shimmer now runs on hover only; the word-by-word arrival stays.
4. A later unscoped `.site-header { backdrop-filter: blur(12px) }` overrode the mobile rule that removes the blur from the solid white header (GPU work on every scroll frame, nothing visible). Blur is now ≥640 px only.
