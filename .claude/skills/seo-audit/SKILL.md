# SEO Audit Skill
1. Read repository instructions and inspect existing audit scripts before suggesting changes.
2. Execute existing read-only audit and preserve original output.
3. Analyze robots, sitemap, canonical, metadata, structured data, content, internal links and image performance.
4. Mark GSC, GA4, CrUX and rankings **unverified** unless authenticated evidence is present.
5. Report evidence, severity, affected URL, reproducibility and recommended fix.
6. Never modify production, publish content, submit forms, generate backlinks or merge a PR.
7. For fixes, use a feature branch, tests and draft PR for human approval.
